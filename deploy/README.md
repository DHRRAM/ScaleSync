# ScaleSync Deployment Assets

- `install_maya_module.py`: writes user Maya `.mod` file.
- `install_blender_addon.py`: writes the Blender add-on bootstrap.
- `build_blender_extension.py`: builds the self-contained artist-installable Blender ZIP.
- `install_houdini_package.py`: writes user Houdini package JSON.
- `maya/`: Maya plugin/module templates and launch scripts.
- `blender/`: Blender add-on bootstrap documentation and template.
- `houdini/`: Houdini package templates and HDA build helper scripts.
